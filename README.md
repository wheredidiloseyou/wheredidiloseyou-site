# Where Did I Lose You — public site

GitHub Pages site for Privacy Policy, Terms of Service, and TikTok URL verification.

## TikTok verification
1. In TikTok Developer Console, download the signature `.txt` file.
2. Put that exact file in this folder (same filename TikTok gives you).
3. Commit and push.
4. Open `https://<user>.github.io/<repo>/<exact-filename>.txt` and confirm it loads.
5. Click Verify in TikTok.
